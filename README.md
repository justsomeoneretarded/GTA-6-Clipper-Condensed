# GTA VI Condensed Gameplay

Follows one GTA VI mission, ride, or scene in chronological order. It keeps at least four minutes of meaningful footage with setup, escalation, and an ending.

Add `GEMINI_API_KEY` under **Settings → Secrets and variables → Actions**. This editor checks every 20 minutes for a finished Shorts run with an eligible catalog. It automatically starts one production run using that catalog and this repository's Gemini key. [Shorts repository](https://github.com/justsomeoneretarded/GTA-6-Clipper-shorts)

You can also open **Actions → Produce GTA VI Condensed Gameplay → Run workflow** to edit the latest catalog manually. Download the MP4, thumbnail, captions, title, description, and source notes from the production run's **Artifacts** section. Review and post the video manually.

The optional `YOUTUBE_COOKIES` repository secret authenticates YouTube footage downloads from this editor.
